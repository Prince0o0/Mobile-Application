# พอดี — เวอร์ชันพื้นฐานสำหรับฝึก Flutter

โค้ดแอปทั้งหมดอยู่ใน `lib/main.dart` มีคำอธิบายภาษาไทย ใช้โทนเทา ส้ม ขาว
เป็นโครงงานตัวอย่างสำหรับมหาวิทยาลัยนเรศวร ไม่ใช่ระบบที่มหาวิทยาลัยรับรองหรือระบบบัญชีนิสิตจริง
เวอร์ชันเดิมที่มีเซิร์ฟเวอร์และเมนู 5 ช่องยังเก็บแยกไว้ใน `student_budget`

## สิ่งที่ปรับให้ง่ายขึ้น

- ไม่มีแถบเมนูด้านล่าง ใช้ปุ่มธรรมดาและตัวแปร `page` เลือกหน้าจอ
- ใช้ `setState()` อัปเดตข้อมูล ไม่ใช้ระบบจัดการสถานะแยก
- มี 3 หน้า: เข้าสู่ระบบ → คำนวณงบประมาณ ↔ ตั้งค่า/ข้อมูลผู้ใช้
- หน้าตั้งค่ามีข้อมูลผู้ใช้ เกี่ยวกับแอป ปุ่มกลับ และออกจากระบบ
- พักเมนูเตือนบิล หารเงิน สถิติ และการตั้งค่าขั้นสูงไว้ก่อน ให้ตรงกับงานคำนวณในระยะแรก
- ใช้บัญชีทดลองหนึ่งบัญชี ไม่ต้องติดตั้ง Node.js หรือฐานข้อมูล
- บันทึกเฉพาะแผนล่าสุดในเครื่องด้วย `shared_preferences` ซึ่งเป็นส่วนเสริมที่แยกอ่านทีหลังได้

## วิธีเปิดโปรเจกต์

โฟลเดอร์นี้มีซอร์ส Flutter พร้อมโครง Android/Web แล้ว
เปิด Terminal ในโฟลเดอร์นี้แล้วทำตามลำดับ:

```powershell
flutter pub get
flutter run
```

เลือกมือถือ Android/Emulator ที่เชื่อมต่อไว้ หรือทดลองใน Chrome ด้วย `flutter run -d chrome`
ถ้ามีโปรเจกต์ Flutter อยู่แล้ว ให้นำ `lib/main.dart` และ dependency `shared_preferences`
ไปใส่ในโปรเจกต์นั้น ส่วนไฟล์ทดสอบนี้ import ตามชื่อ `student_budget_beginner`
จึงต้องปรับชื่อ import หากใช้ชื่อโปรเจกต์อื่น

บัญชีทดลอง: **65000001** / **Demo@1234**
ข้อมูลล็อกอินกำหนดอยู่ในโค้ดเพื่อฝึกเงื่อนไข if เท่านั้น ใช้ข้อมูลสมมติ
ไม่มีการสมัครสมาชิก เปลี่ยนรหัสผ่าน หรือเชื่อมบัญชีมหาวิทยาลัย

## สูตรคำนวณ

เงินที่เหลือ = รายรับทั้งหมด − รายจ่ายประจำรวม − เงินออม

งบต่อวัน = เงินที่เหลือ ÷ จำนวนวันที่ต้องใช้เงิน

ตัวอย่าง: (9,000 − 3,000 − 1,500) ÷ 30 = **150 บาทต่อวัน**

กรอกตัวเลขทั้ง 4 ช่อง จำนวนเงิน 0–1,000,000 บาท ทศนิยมไม่เกิน 2 ตำแหน่ง
จำนวนวันเป็นจำนวนเต็ม 1–366 วัน กรณีไม่มีรายจ่ายหรือเงินออมให้ใส่ 0
เก็บตัวเลขเงินเป็นสตางค์และปัดงบรายวันลง เช่น 100 ÷ 3 ได้ 33.33 บาท
ถ้าเงินไม่พอ จะแสดงงบ 0 บาทและยอดเงินที่ขาด เมื่อแก้ตัวเลขต้องกดคำนวณใหม่
นี่คือแผนแบ่งเงินในช่วงวันที่ผู้ใช้ระบุ ยังไม่ได้หักรายจ่ายที่ใช้จริงในแต่ละวัน

## เริ่มอ่านโค้ดตรงไหน

| ส่วน | ใช้ทำอะไร |
| --- | --- |
| `main()` และ `MyApp` | เปิดแอปและกำหนดสี |
| ตัวแปร `page` | 0 เข้าสู่ระบบ, 1 คำนวณ, 2 ตั้งค่า |
| `TextEditingController` | อ่านข้อความที่ผู้ใช้กรอก |
| `login()` | ตรวจรหัสนิสิต 8 หลักและบัญชีทดลอง |
| `readMoney()` | ตรวจและแปลงจำนวนเงินเป็นสตางค์ |
| `calculateBudget()` | ลบค่าใช้จ่ายและเงินออม แล้วหารจำนวนวัน |
| `setState()` | แจ้งให้ Flutter แสดงข้อมูลที่เปลี่ยน |
| `loginPage()`, `budgetPage()`, `settingsPage()` | สร้างหน้าจอแต่ละหน้า |
| `loadPlan()`, `savePlan()` | อ่านและบันทึกตัวเลข 4 ช่องในเครื่อง |
| `logout()` | กลับหน้าเข้าสู่ระบบและล้างข้อมูลบนหน้าจอ |
| `dispose()` | คืนทรัพยากรของช่องกรอกเมื่อเลิกใช้หน้าจอ |

ให้เริ่มจากหน้าและปุ่ม → อ่านค่าจากช่องกรอก → if ตรวจข้อมูล → สูตรคำนวณ → setState
แล้วค่อยอ่านส่วนบันทึกข้อมูลซึ่งมี `Future`, `async`, `await` และ `try/catch` เพิ่มมา
หากห้องเรียนยังไม่สอนการบันทึก ให้ศึกษาและสาธิตปุ่มคำนวณก่อน ปุ่มบันทึกเป็นส่วนเสริม

แผนที่บันทึกจะคงอยู่เมื่อปิดแอป แต่ไม่ซิงก์ข้ามเครื่องและอาจหายเมื่อถอนการติดตั้งหรือล้างข้อมูลแอป
ข้อมูลที่แก้ไขแต่ยังไม่กดบันทึกจะหายเมื่อออกจากระบบ ไม่บันทึกรหัสผ่านหรือสถานะล็อกอิน
